The referral feature works end-to-end (verified by live capture test + runtime reward test: both users went 0 -> 25 credits).

- Capture: `login?mode=register&ref=CODE` link (generated by ReferralTab in settings.tsx) matches the `?ref=` param read on signup. Stored at email verify + OAuth callbacks.
- Reward trigger: pays out ONLY when the invited friend connects an email inbox (Gmail/Outlook/IMAP). Until then the referral row sits at status 'registered' and NObody gets credits.

**Why it looks broken:** rewards never appear in testing unless the invited account actually connects a mailbox. This is intentional anti-abuse design and the owner explicitly chose to KEEP the connect-inbox trigger (do not change it to fire on signup without asking).

**How to apply:** if asked again to "fix referrals," do not assume the code is broken — confirm whether the test friend connected an inbox first. `referral-banner.tsx` is dead/unused code; the real UI is `ReferralTab` in `client/src/pages/settings.tsx`.
